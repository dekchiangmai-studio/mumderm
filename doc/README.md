# doc

เอกสารหลักของโปรเจกต์ MUMDERM

## Files

| File | Description |
|------|-------------|
| `plan.md` | Version roadmap, database model, folder structure — **source of truth** สำหรับ scope ทุก version |
| `PROJECT_PROMPT.md` | Product concept, tech stack, coding rules, UX flow, และ MVP constraints |

## How to Use

- **เริ่มทำ version ใหม่** → อ่าน `plan.md` เพื่อดู scope ของ version นั้น
- **ต้องการเข้าใจ product** → อ่าน `PROJECT_PROMPT.md`
- **ดูว่าทำอะไรไปแล้ว** → อ่าน `CHANGELOG.md` (อยู่ที่ root)
- **ดู architecture ปัจจุบัน** → อ่าน `ARCHITECTURE.md` (อยู่ที่ root)
